# Използване на готовия доклад

Отворете `index.html` в браузър. Визуализациите и филтрите са интерактивни и работят без интернет.

`preview.png` е статичен преглед на началния изглед. Данните за интерактивния отчет са вградени в HTML, а `report_data.json` ги съдържа отделно за проверка.

Ако ползвате GitHub Pages, задайте папка с копие на `index.html` като основна страница на публикацията.
