# Airbnb Analytics — HTML доклад

Тази папка съдържа браузърния вариант на аналитичния доклад за Airbnb. Той показва резервации, приходи, оценки и видове имоти чрез интерактивни графики и филтри.

## Стартиране

Отворете `index.html` в Chrome, Edge или Firefox. Файлът `plotly.min.js` трябва да остане в същата папка — той се използва за графиките. Не е необходим уеб сървър или връзка към SQL Server.

`preview.png` показва оформлението, а `report_data.json` съдържа отделно подготвените демонстрационни данни. Браузърният доклад не се обновява автоматично от базата и се поддържа независимо от Power BI версията.
